# Qubic Wallet setup guides

Install Qubic Wallet, create an account and keep the seed safe. Fifteen guides, written against the
current release rather than an older build.

Start with [how to install Qubic Wallet on Windows, macOS and Linux](qubic-wallet-install-windows-macos-linux.md),
then create your first account with a backup proof you can actually check.

Every guide links the official release page and states the file size, so you can confirm the installer
you downloaded is the one you meant to run.

New to the product? Read [what Qubic Wallet is](https://github.com/qubic-wallet/qubic-wallet-trust/blob/main/what-is-qubic-wallet.md)
first, then come back here to install it.
